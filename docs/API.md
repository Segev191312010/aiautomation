# TradeBot API

The dated OpenAPI snapshot
[`2026-07-phase-b-openapi.json`](openapi/2026-07-phase-b-openapi.json) is the
Phase B contract-verification schema captured from the canonical FastAPI app at
the B0 baseline. It is evidence for the B1/B2 inventory, not an eternal manual
API specification; regenerate it when the backend contract changes.

Snapshot metadata:

- source commit: `d67da67bd6a5d8d733f67e759bc8cb399a10cc49`;
- title/version: `Trading Dashboard` / `2.0.0`;
- paths: 176;
- method operations: 123 GET, 54 POST, 5 PUT, 6 DELETE.

The snapshot contains the current `/api/positions/`, `/api/orders/`,
`/api/alerts/`, `/api/swing/`, and `/api/autopilot/` route families. The future
`POST /api/session/bootstrap` route is intentionally not present yet; it is a
B7 implementation deliverable.

The snapshot was generated by importing `main.app` and calling
`app.openapi()` without entering FastAPI lifespan. This avoids starting the
runtime lock, IBKR connection, database initialization, or background loops
while capturing a static contract.
